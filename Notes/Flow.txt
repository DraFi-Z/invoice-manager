==============================================Login-Flow=========================================

POST /api/auth/login  { email, password }
            ↓
JwtAuthenticationFilter runs
  → no Authorization header found
  → calls filterChain.doFilter() — passes through
            ↓
SecurityConfig checks — /api/auth/** is permitAll()
  → request allowed through
            ↓
AuthController.login() receives LoginRequest
            ↓
AuthService.authenticate(email, password)
  → userRepository.findByEmail(email)
  → checks user.isActive()
  → passwordEncoder.matches(rawPassword, storedHash)
  → returns User if all checks pass
            ↓
JwtService.generateToken(email, role)
  → builds JWT payload with email as subject, role as claim
  → signs with secret key
  → returns token string
            ↓
AuthController builds LoginResponse
  → token, email, role, fullName
            ↓
200 OK — caller receives their token


===============================================Authenticate-Request Flow========================================
GET /api/invoices
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
            ↓
JwtAuthenticationFilter runs
  → reads Authorization header
  → strips "Bearer " prefix → gets raw token
  → jwtService.isTokenValid(token)
      → parses token, verifies signature, checks expiry
      → returns true
  → jwtService.extractEmail(token) → "ahmad@billing.com"
  → jwtService.extractRole(token) → "ADMIN"
  → creates UsernamePasswordAuthenticationToken
      with email as principal
      and ROLE_ADMIN as authority
  → sets it in SecurityContextHolder
  → calls filterChain.doFilter() — passes through
            ↓
SecurityConfig checks — /api/invoices requires authenticated()
  → SecurityContextHolder has authentication → allowed
            ↓
InvoiceController.getAllInvoices() executes
  → returns invoice list
            ↓
200 OK


===========================================================Request with no token===========================================================

GET /api/invoices
  (no Authorization header)
            ↓
JwtAuthenticationFilter runs
  → no Authorization header found
  → calls filterChain.doFilter() — passes through
  → SecurityContextHolder has NO authentication
            ↓
SecurityConfig checks — /api/invoices requires authenticated()
  → no authentication in context → BLOCKED
            ↓
401 Unauthorized

============================================================Wrong role ======================================================================
POST /api/users
Authorization: Bearer <token with role ACCOUNTANT>
            ↓
JwtAuthenticationFilter runs
  → valid token
  → sets ROLE_ACCOUNTANT in SecurityContextHolder
            ↓
SecurityConfig checks — /api/users requires hasRole("ADMIN")
  → ROLE_ACCOUNTANT ≠ ROLE_ADMIN → BLOCKED
            ↓
403 Forbidden

============================================================= Docker Contenarization =================================================================

docker compose up --build
        ↓
Docker reads docker-compose.yml
        ↓
Sees app service has build: .
→ Reads Dockerfile
→ Stage 1 (build):
    - Pulls eclipse-temurin:21-jdk-alpine
    - Sets WORKDIR /app
    - Copies pom.xml, .mvn, mvnw
    - Downloads all Maven dependencies (cached if pom.xml unchanged)
    - Copies src/
    - Runs mvnw clean package → produces target/app.jar
→ Stage 2 (final):
    - Pulls eclipse-temurin:21-jre-alpine (fresh, clean)
    - Copies only app.jar from Stage 1
    - Sets ENV TZ=UTC
    - Sets ENTRYPOINT
→ Final image is ready (small, no build tools)
        ↓
Starts postgres container
→ Injects POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB, PGTZ
→ PostgreSQL initializes, creates billing_db and billing_user
→ Docker runs healthcheck every 5s: pg_isready -U billing_user -d billing_db
→ After healthcheck passes → postgres marked as healthy
        ↓
Starts app container (only now, because condition: service_healthy)
→ Injects all SPRING_* environment variables
→ SPRING_PROFILES_ACTIVE=prod → loads application-prod.properties
→ application-prod.properties reads ${SPRING_DATASOURCE_URL} from env
→ JVM starts: java -Duser.timezone=UTC -jar app.jar
→ Spring Boot reads properties → configures HikariCP connection pool
→ HikariCP connects to postgres:5432 (service name on billing-network)
→ Flyway runs migrations → validates schema
→ Hibernate validates entities
→ DataSeeder runs → creates admin user if no users exist
→ Application ready on :8080
        ↓
Port mapping:
  Your Windows :5432 → postgres container :5432
  Your Windows :8080 → app container :8080
        ↓
Postman hits localhost:8080 → reaches your Spring Boot app
Spring Boot hits postgres:5432 → reaches PostgreSQL
